# 放弃 Marketplace 无密钥发布

| 字段 | 内容 |
| --- | --- |
| 状态 | Completed |
| 更新 | 2026-08-06 |
| 目标 | 记录 Marketplace 发布方式的最终决策 |
| 执行授权 | 已授权：放弃自动化并恢复网页手动发布 |

## 1. 结论与设计

原计划通过 `GitHub Actions OIDC → Entra 应用 → VS Code Marketplace` 取代 PAT。实际配置流程比预期复杂，且 Marketplace 当前交互与相关说明并不完全一致；对于发布频率较低的个人项目，其维护成本高于收益。

最终决定：

- 放弃 Marketplace 无密钥发布和自动发布工作流。
- 不为此恢复或购买 Azure 订阅，也不维护 Entra 联合凭据、Client Secret 或 Marketplace PAT。
- 以后在开发者最终确认后，通过 Marketplace Publisher 管理页面手动上传已经验证并发布到 GitHub Release 的同一 VSIX。
- GitHub Release 与 Marketplace 是两个独立发布步骤，均不得把“准备发布”视为最终发布授权。

## 2. 待确认

无。

## 3. 开发者操作

正式发布时按 `docs/release.md` 的 Marketplace 手动发布步骤执行；开发者只需完成 Microsoft 账号登录和网页上传等必须由本人完成的交互。

## 4. 验收

- [x] 不保留 PAT、Client Secret 或其他长期发布凭据。
